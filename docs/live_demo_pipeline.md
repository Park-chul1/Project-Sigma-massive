# Daily WRDS data and paper execution

All research prices and fundamentals originate in Compustat through WRDS. IBKR is used for account state and order routing. The NASDAQ universe follows historical exchange membership and always excludes the bottom 20% by same-date market capitalization.

Build current inputs after Compustat has published the desired session:

```bash
export WRDS_USERNAME="your_wrds_username"
python scripts/run_clean_pipeline.py --start 2023-01-01 --end 2026-10-05
```

Use `data/processed_wrds` for factor inputs and `data/processed_wrds/daily_bars.parquet` for bars. Run the after-close job before preparing next-session paper orders:

```bash
python scripts/run_after_close_job.py --date 2026-10-05 --config configs/daily_live.yaml
```

To warm an optional daily WRDS cache after building the universe inputs:

```bash
python scripts/run_live_demo_pipeline.py --prefetch-only --asof 2026-10-05
```

Compustat is a daily feed. The former delayed intraday fetch/rebalance loop is replaced by this daily prefetch command. `DATA_PROVIDER` accepts only `wrds` or explicit `cache`; cached bars must retain `source=compustat_wrds`, and missing authentication never selects another provider.

Paper orders map stable model IDs to validated broker symbols. Share sizing uses the saved unadjusted signal-date close; absent or ambiguous symbol mappings/prices stop the submission. The broker account/order monitoring jobs remain available without downloading alternate market prices.

`PAPER_TRADING=true` and `ENABLE_REAL_TRADING=false` remain the defaults. Existing historical reports are not regenerated by a code migration: rebuild the WRDS inputs and rerun reports before using them.
